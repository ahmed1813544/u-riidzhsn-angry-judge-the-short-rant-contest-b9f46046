A tiny stdlib-only Python program that writes one short, funny rant — about a self-checkout machine with a god complex — to `entry.txt` for make.fun's "Angry Judge: The Short Rant Contest" bounty. The rant is fixed text, so the output is deterministic and byte-identical on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the rant to `./output/entry.txt` (1–400 characters, UTF-8).
